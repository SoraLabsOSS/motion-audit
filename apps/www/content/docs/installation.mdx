## Upcoming Tooling

Motion Audit will be accessible across multiple developer environments:

- **CLI Runner**: Run automated audits against production URLs or local dev servers directly from your terminal or CI/CD pipelines.
- **Browser Extension**: Real-time visual diagnostics, frame-rate profiling, and layer inspection inside Chromium DevTools.
- **Programmatic SDK**: Integrate motion scoring into automated testing frameworks (Playwright, Puppeteer).
